# バイト偏差値

アルバイトの **時給・勤務時間・待遇** を入力すると、全国の投稿データと比べた「偏差値」と、RPG の職業に例えた「クラス」（スライム〜伝説の勇者）が分かる Web サイトです。

- ログイン不要。対象は大学生以上
- データはユーザーの投稿（自己申告）だけで集計します。公的統計は使いません
- スマホ表示優先・ダークモード対応

## 主な機能

| ページ | 内容 |
| --- | --- |
| トップ（`/`） | サイトの説明と入力フォーム |
| 結果（`/result.html`） | クラスのイラストと総合偏差値、重みスライダー、項目別偏差値、同業種・同県での偏差値、時給の分布グラフ、X でシェア |
| クラス図鑑（`/classes.html`） | 全 9 クラスのイラスト・名前・偏差値の範囲・ひとこと（自分のクラスを強調） |
| 全国データ（`/stats.html`） | 総投稿数、業種別の平均時給ランキング、都道府県別の平均時給 |
| 利用規約（`/terms.html`） | 利用規約・プライバシーポリシー |

## 偏差値の計算

サーバーは生データの保存と集計（件数・平均・母標準偏差・ヒストグラム）だけを行い、偏差値・重み付け・クラス判定はブラウザ側（`public/js/calc.js`）で計算します。

- 偏差値 = 50 + 10 ×（自分の値 − 平均）÷ 母標準偏差
- 項目別偏差値
  - 時給偏差値：時給
  - 稼ぎ偏差値：月収見込み（時給 × 週の勤務時間 × 52 ÷ 12）
  - 待遇偏差値：チェックした待遇の数（0〜5）
- 総合偏差値 = 項目別偏差値を重み（各 0〜10、初期値 時給5：稼ぎ2：待遇3）で加重平均
  - プリセット：時給重視（10:3:1）／バランス（5:5:5）／待遇重視（2:2:10）
  - 重みがすべて 0 のときは総合偏差値・クラスを出さない
  - 重みはブラウザ（localStorage）に保存
- 比較範囲：全国／同じ業種／同じ都道府県。10 件未満は「データ不足」
- 全国が 30 件未満の間は「参考値」「データ収集中（現在 n 件）」と表示
- 標準偏差 0 のときは偏差値 50、データ 1 件以下は計算しない
- 表示は小数第 1 位。クラス判定も表示と同じ丸めた値で行う

### クラス

クラスの区切り・名前・ひとこと・イラスト（32×32 のドット絵）は **`public/js/classes.js` の 1 ファイル** にまとまっています。
初期データは `tools/gen_classes.py`（Python 3）で生成しました。ドット絵を描き直したいときはスクリプトを編集して `python tools/gen_classes.py` を実行するか、`classes.js` を直接編集してください（スクリプトを再実行すると上書きされます）。

## 技術構成

- フロント：Cloudflare Pages（フレームワークなしの HTML / CSS / JavaScript、ES Modules）
- API：Cloudflare Pages Functions
- DB：Cloudflare D1
- ボット対策：Cloudflare Turnstile

```
public/              静的ファイル（Pages の出力ディレクトリ）
  js/calc.js         偏差値・重み付け・クラス判定（純粋な関数）
  js/classes.js      クラス定義とドット絵データ
  js/constants.js    都道府県・業種・待遇などの定数（フロントとサーバーで共有）
  _headers           セキュリティヘッダー（CSP など）
functions/api/       API（posts.js, stats.js, config.js）
functions/_lib/      入力チェック・集計・IP ハッシュ・Turnstile 検証
migrations/          D1 のテーブル定義
seed/dev-seed.sql    ローカル確認用のダミーデータ（本番では使わない）
test/                ユニットテスト（node:test）
tools/               ドット絵・ダミーデータの生成スクリプト（Python）
```

### API

| メソッド | パス | 内容 |
| --- | --- | --- |
| `POST` | `/api/posts` | 投稿を保存し、比較に必要な集計値を返す（Turnstile 必須） |
| `GET` | `/api/stats` | 全体・業種別・都道府県別の件数・平均・標準偏差、時給のヒストグラム |
| `GET` | `/api/config` | フロントに渡す公開設定（Turnstile のサイトキー） |

個々の投稿は返さず、集計値だけを返します。10 件未満のグループは件数だけ返します。

### 荒らし・スパム対策

- 投稿時に Cloudflare Turnstile でボット判定
- IP アドレスはソルト付き SHA-256 ハッシュで保存（生の IP は保存しない）。同じハッシュから 1 日（日本時間）5 件まで
- サーバー側でも入力値の範囲チェック（時給 800〜10000 円の整数、週 1〜60 時間など）
- 外れ値の除外：全体が 30 件以上になると、時給・月収見込みが平均から 4 標準偏差より離れた投稿を自動で集計から除外。個別に除外したい投稿は `excluded = 1` にする

```bash
npx wrangler d1 execute baito-hensachi --local --command "UPDATE posts SET excluded = 1 WHERE id = 123"
```

## ローカルでの起動方法

必要なもの：Node.js 20 以上

```bash
# 1. 依存パッケージ（wrangler）をインストール
npm install

# 2. 環境変数ファイルを作る（中身は Cloudflare のテスト用キー。ソルトは好きな長い文字列に変更）
cp .dev.vars.example .dev.vars

# 3. ローカルの D1 にテーブルを作る
npm run db:migrate

# 4. （任意）ダミーデータを 300 件入れる
npm run db:seed

# 5. 起動 → http://localhost:8788 を開く
npm run dev
```

- `.dev.vars.example` の Turnstile キーは Cloudflare 公式の「常に成功する」テスト用キーです。ローカルではそのまま動きます
- ダミーデータを消すときは `npm run db:reset`

### テスト

```bash
npm test
```

`test/` に計算ロジック（偏差値・重み付け・クラス判定）、クラスデータ、サーバー側の入力チェック・集計のテストがあります。

## 秘密情報について

`TURNSTILE_SECRET_KEY` と `IP_HASH_SALT` は **絶対にコミットしないでください**。

- ローカル：`.dev.vars`（`.gitignore` 済み）
- 本番：Cloudflare ダッシュボードの Pages プロジェクト → 設定 → 環境変数（シークレット）

本番にデプロイする場合は、`wrangler.toml` の `database_id` を `npx wrangler d1 create baito-hensachi` で発行された ID に置き換え、`npx wrangler d1 migrations apply baito-hensachi --remote` でテーブルを作成してください。

## 注意

このサイトの数値は投稿者の自己申告に基づく参考値で、公的統計ではありません。
